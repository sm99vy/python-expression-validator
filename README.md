# 🧮 Validador de Expressões Matemáticas em Python

Programa desenvolvido em Python para verificar se uma expressão matemática possui os parênteses corretamente abertos e fechados.

## Funcionalidades

- Recebimento de uma expressão digitada pelo usuário
- Identificação dos parênteses presentes na expressão
- Verificação do balanceamento entre abertura e fechamento
- Exibição do resultado da validação

## Tecnologias

- Python 3

## Conceitos praticados

- Manipulação de strings
- Estruturas condicionais
- Listas
- Laços de repetição
- Validação de dados

## Como executar

```bash
python expression-validator.py
```

## Objetivo

Praticar manipulação de dados e lógica de validação, trabalhando com a identificação de estruturas em expressões matemáticas.
